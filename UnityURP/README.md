- 有人被抓时，狱警沿可通行路线步行押往最近的 **HOLDING**。押送途中也能救援。搭档被捕时，HUD 显示下一岔口方向和距离，靠近后按住 **F**。AI 可以沿路去救被捕的玩家。押送卡住或救援超时会在当前位置释放，并提前 24 秒封锁。释放后有 12 秒脱身窗口。
- 冲刺按实际位移扣体力。正面贴墙时手臂会稍微收近，双手用独立渲染层，墙面不会把它们裁掉。
- 真搭档收到 **T** 指令时会发出两声回应。模仿者穿同款外套，靠近可以看到异常面部。测试狱警和双手时使用 Unity 菜单 **Twin Labyrinth → Stage Guard and Hands**。

- 两人要在 **10 分钟**内接通两处配电箱并一起到达出口。HUD 展示协议、剩余时间、下一步和搭档距离。最终封锁后按 **R** 重开。
- 自由活动允许探索。肃清巡查用光线和奔跑累计探测。身份异常期间别长时间注视模仿者。生命异常时靠近搭档，按住 **F** 两秒进行救援，错过窗口会扣除 25 秒。最后两分钟清算期间，两人保持在 9 米内可以避免扣时。
- 体力耗尽才播放喘息，恢复后淡出。看见无遮挡的人物时播放低音双心跳，移开视线后衰减。战斗与联机不在此试玩版范围内。

- 在现有断电迷宫中加入 AI 搭档。按 **T** 切换跟随和原地等候。先启动 **RELAY A**，带搭档靠近 **RELAY B** 再按 **F**，最后两人一起抵达开放的出口。
- 玩家拾取手电后按 **L** 开关。手电独立于监区供电，开灯仍消耗电量，补给点可换电。脚步触发按移动距离计算，冲刺会加快步频。
- 协作版音频可通过 Unity 菜单 **Twin Labyrinth → Update Partner Audio** 更新，来源见音频目录内的 `PartnerAudio-Licenses.txt`。旧场景仍引用 [GboxMikeFozzy 的地铁实录](https://opengameart.org/content/footsteps-0)，CC0，OGG，第 02–06 段。
- 常规走路使用 A2 混凝土实录，冲刺混入 A3 和 A4。配乐在收押区、开始探索、断电和首次看见异常人物时切换。每个角色首次进入视线时，从角色方向播放一声轻微的低弦音，配乐随之压低。
- Unity 菜单 **Twin Labyrinth → Create Partner Protocol** 生成 `Assets/ArtReview/HauntCoop/PrisonCoop.unity`。当前 Windows 和 Web 构建沿用 `Blackout-*` 输出路径，旧版场景保留。

## 鬼屋探索版
