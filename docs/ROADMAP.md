# 后续方向：立体监区与微恐

## 当前基线

当前发布的是单层主体迷宫中的双人联机近战版本。已有六类功能房间、牢房、手电、刀具、囚犯、救援和合作出口。当前画面就是 README 展示的实际效果。

## 两至三层空间（待实现）

先制作两层可玩区，再扩展地下设备区：

- 第一层：入口、值班室、生活区与起点。
- 第二层：主要监区、牢房、医务室、洗衣间及中庭连接桥。
- 地下一层：维修、配电与逃生通道。

主楼梯清楚可辨，辅助通道可解锁；允许透过挑空区域看到另一层的队友。每层有不同用途和地标，避免复制走廊或无提示的反复上下楼。

## 微恐（待调整）

以朋友一起探索为目标：主要通道可辨、有限追逐、安静安全区、低音量短促提示、可观察的危险前兆。避免持续追杀、突然全黑、频繁跳脸、尖叫和血腥特写。

## 优先级

1. 专用第一人称手臂与持握、自然切换道具；改进受击/倒地动作。
2. 两层空间、楼梯、碰撞和联机高度同步。现有服务器主要校验 X/Z，不能只增加楼梯模型就声称完成多层联机。
3. 房间家具与细节统一、微恐灯光节奏和可读性。
4. 主资源拆包、首屏加载、固定托管与异地双人验证。
5. 基础体验稳定后再逐项恢复狱警与监狱协议。
